# In motion — creative direction

## Brief

The owner wants a more dynamic, original product film with Apple/OpenAI-like restraint and energy, recognizable OpenBot UI and animated mascots. The film remains instrumental. It must explain useful work, not become a feature-title slideshow or an extended tool-building tutorial.

## Product reference

The current Mac candidate was inspected alongside `DesktopStudioView.swift`, `DesktopConversationView.swift` and the shared native `StudioPalette.swift`. The installed older OpenBot build had a different sidebar and inspector; it was not used as the baseline. The localhost web runner at port 4310 was unavailable during this pass.

Preserved: conversation-first shell, neutral paper/ink palette, compact identities, contextual inspector, rounded outlined composer, restrained file rows, settings access, authentic colorful character silhouettes. The current source uses dark user bubbles with white text. The film uses Inter, the existing bundled font, rather than claiming an exact SwiftUI font/render match.

`src/studio-film/Character.tsx` deterministically reconstructs the six native character silhouettes. Animation is original film choreography, not a screen recording. Macro mascots outside the window are editorial transitions, not new application controls.

## Claim boundaries outside the film

This is a fictional pre-launch creative asset. Names, accounts, files, budgets, approvals, execution and phone states are staged. The local expense fixture checks the example's arithmetic and parsing only. It does not prove live browser access, reliable autonomous tool creation/repair, a real email send, scheduling or remote continuity. The underlying proposal/approval/coding-model flow and later autonomous reuse must retain their separate verification gates in `CAPABILITY_REVIEW.md`. Nothing was published or sent. This creative pass makes no production capability or release-readiness claim.

All earlier compositions remain available. The new cut needs owner creative approval; technical export checks are not a claim of Apple-level production quality.
